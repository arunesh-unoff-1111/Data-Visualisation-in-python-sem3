Core Characteristics Of Python
High-Level Language (HLL): Abstracts away low-level computer memory and hardware details, making it human-readable and easy to write.
Object-Oriented Programming (OOP) Language: Supports concepts like classes, objects, inheritance, and polymorphism.
Dynamically Typed Language: Variable data types are checked and inferred at runtime rather than compile-time.
Expressive Language: Concise syntax allows complex operations to be written in fewer lines of code.
Interpreted Language: Code is executed line-by-line by an interpreter, which aids in easier debugging.

Types of Operators
Python divides operators into the following main groups:

--- Arithmetic Operators
Used with numeric values to perform common mathematical operations:
Addition (+): Adds values together
Subtraction (-): Subtracts right operand from left
Multiplication (*): Multiplies values
Division (/): Divides left operand by right, returns a float
Floor Division (//): Divides and rounds down to the nearest integer
Modulus (%): Returns the division remainder
Exponentiation (): Raises left operand to the power of right

Assignment Operators
Used to assign values to variables:
Assignment (=)

Subtract and Assign (-=)
Multiply and Assign (*=)
Divide and Assign (/=)
Floor Divide and Assign (//=)
Modulus and Assign (%=)
